# 매수 타이밍 평가표

종목 하나를 받아 **기술적 분석 · 펀더멘털/전망 · 뉴스 심리** 세 영역을 각각 0~100점으로 채점하고,
가중 평균(기본 40 / 40 / 20)으로 종합 점수와 등급을 낸다.
점수 계산은 반드시 `scripts/analyze.py`로 한다. 머릿속으로 계산하지 않는다(매번 같은 기준을 지키기 위해).

## 1단계: 종목 확정
- 종목명을 티커로 바꾼다. 한국 코스피는 `005930.KS`, 코스닥은 `.KQ`, 미국은 `NVDA`, 코인은 `BTC-USD`.
- 이름이 애매하면(예: "현대") 후보를 보여주고 사용자에게 고르게 한다.

## 2단계: 시세·지표·실적 자동 조회 시도
```bash
python scripts/analyze.py <티커>
```
- 성공하면 JSON 결과가 나온다. 3단계 뉴스로 넘어간다.
- `자동 조회 실패`가 나오면(네트워크 차단 등) 2-B로 간다.

### 2-B: 웹 검색으로 값 모으기
웹 검색으로 아래 값을 **최신 날짜 기준**으로 찾는다. 못 찾은 값은 비워 둔다(스크립트가 중립/제외 처리한다). 값을 지어내지 않는다.

| 키 | 의미 | 찾는 곳 예시 |
|---|---|---|
| close | 현재가 | 네이버 금융, Yahoo Finance, Investing.com |
| rsi | RSI(14) | Investing.com 기술적 분석 페이지 |
| bb_pctb | 볼린저 %B = (현재가−하단)/(상단−하단) | 볼린저 상·하단 값을 찾아 직접 계산 |
| macd_hist, macd_hist_prev | MACD − 시그널 (오늘, 전일) | Investing.com 기술적 분석 |
| macd_recent_cross | 최근 5거래일 안에 골든크로스 여부 | 기술적 분석 기사·차트 |
| ma20, ma60, ma120 | 이동평균 | Investing.com(20·50·100·200일선이면 가까운 값 사용) |
| stoch_k, stoch_d | 스토캐스틱 슬로우 | Investing.com |
| forwardPE, trailingPE, pegRatio, priceToBook | 밸류에이션 | 네이버 금융, FnGuide, Yahoo Finance |
| revenueGrowth, earningsGrowth | 최근 분기 매출·이익 성장률(YoY, 소수) | 실적 발표 기사, FnGuide |
| returnOnEquity, profitMargins | ROE, 순이익률(소수) | |
| debtToEquity | 부채비율(%, 숫자) | |
| targetMeanPrice, numberOfAnalystOpinions | 평균 목표주가, 애널리스트 수 | 증권사 컨센서스, FnGuide, MarketBeat |
| recommendationMean | 투자의견 평균(1=강력매수 ~ 5=매도) | Yahoo Finance; 국내는 "매수" 비율로 환산(전원 매수≈1.5) |
| eps_growth_next_year | 내년 EPS 성장 예상치(소수) | 컨센서스 |

모은 값을 `values.json`으로 저장한다(형식은 `scripts/analyze.py` 맨 위 설명 참고).

## 3단계: 뉴스 심리 채점
- 최근 1~2주 뉴스를 검색한다. 한국 종목은 한국어로, 해외 종목은 영어와 한국어 둘 다 검색한다.
- 실적·가이던스, 수주·신제품, 규제·소송, 수급(외국인·기관), 업황 이슈를 중심으로 0~100점을 매긴다.
  - 0~20: 큰 악재(실적 쇼크, 소송 패소, 규제 직격)
  - 21~40: 악재 우세
  - 41~60: 중립 또는 호재·악재가 섞임
  - 61~80: 호재 우세
  - 81~100: 큰 호재(어닝 서프라이즈, 대형 수주)
- 긍정 요인과 부정 요인을 각각 1~3개씩 출처와 함께 정리해 둔다.

## 4단계: 종합 점수 계산
```bash
python scripts/analyze.py <티커> --sentiment <뉴스점수>     # 2단계 자동 조회가 됐을 때
python scripts/analyze.py --values values.json             # 2-B로 값을 모았을 때 (sentiment 키 포함)
```
사용자가 가중치를 바꿔 달라고 하면 values.json의 `weights`를 바꾼다.

## 5단계: 답변 형식 (한국어)
```
## 🎯 <종목명> (<티커>) 매수 타이밍 평가표
기준일: YYYY-MM-DD · 현재가: ...

### 종합 <점수>점 — <등급>
<한두 문장 요약>

| 영역 | 점수 | 가중치 | 한 줄 요약 |
|---|---|---|---|
| 📊 기술적 분석 | ..점 | 40% | ... |
| 🏢 펀더멘털/전망 | ..점 | 40% | ... |
| 📰 뉴스 심리 | ..점 | 20% | ... |

### 📊 기술적 분석 상세
(스크립트 결과의 항목 표: 항목 / 현재값 / 점수/배점 / 해석)

### 🏢 펀더멘털 · 실적 · 향후 예상치 상세
(같은 형식. 데이터 없는 항목은 "-")

### 📰 뉴스 심리
👍 긍정 요인 … 👎 부정 요인 … (출처 링크)

### 💡 매매 전략 참고
- 분할매수 후보 가격대: 볼린저 하단, 60일선, 120일선 등 '참고가격' 값 기준으로 2~3개
- 이런 신호가 나오면 점수가 바뀐다: (예: RSI 30 이하 진입, 실적 발표일, 60일선 이탈)

※ 공개 데이터 기반 참고용 점수이며 투자 권유가 아닙니다. 최종 판단과 책임은 투자자 본인에게 있습니다.
```

## 지켜야 할 것
- 숫자는 실제로 찾은 값만 쓴다. 못 찾은 값은 "-"로 두고, 어떤 값이 빠졌는지 답변 끝에 밝힌다.
- 데이터 기준일과 주요 출처를 반드시 적는다. 실시간이 아니라 지연 시세일 수 있음을 알린다.
- ETF·코인·원자재는 펀더멘털 점수가 자동으로 빠진다. 그 사실을 표에 "평가 제외"로 표시한다.
- 여러 종목을 비교해 달라고 하면 종목마다 점수를 내고, 마지막에 종합 점수 순위표를 붙인다.

## 등급 기준
| 점수 | 등급 |
|---|---|
| 75 이상 | 강력 매수 타이밍 |
| 60~74 | 분할 매수 고려 |
| 45~59 | 관망 |
| 30~44 | 매수 보류 |
| 30 미만 | 매수 회피 |
